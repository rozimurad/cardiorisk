# CardioRisk - Kardiyovasküler Risk Takip Sistemi

Bu proje, hastaların kardiyovasküler risklerini hesaplayan ve takip eden PHP tabanlı bir web uygulamasıdır.

## Kurulum Adımları
1. Bu depoyu bilgisayarınıza indirin veya klonlayın.
2. Dosyaları XAMPP/WAMP kullanıyorsanız `htdocs` veya `www` klasörüne taşıyın.
3. phpMyAdmin'i açın ve `cardiorisk` adında yeni bir veritabanı oluşturun.
4. `Database/cardiorisk_final.sql` dosyasını bu veritabanına içe aktarın (Import).
5. `CardioRisk/config/db.php` dosyasını açın ve kendi yerel veritabanı bilgilerinizi (kullanıcı adı, şifre) girin.
6. Tarayıcınızdan `http://localhost/CardioRisk` adresine giderek uygulamayı çalıştırın.
